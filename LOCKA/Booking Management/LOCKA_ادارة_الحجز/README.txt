LOCKA - إدارة الحجز

هذا الجزء مخصص لواجهة إدارة الحجز وربطها مع واجهات بقية الفريق.

1) التمديد والأسعار:
- ساعة: 3 ريال
- يوم: 10 ريال
- كل يوم إضافي: 10 ريال
- أسبوع كامل (7 أيام): 70 ريال
- الحد الأعلى للتمديد: أسبوع.

2) الدفع:
- لا توجد واجهة دفع داخل هذا الجزء.
- يوجد زر «الانتقال للدفع» داخل نافذة التمديد فقط.
- عدّلي قيمة PAYMENT_PAGE_URL في script.js إلى رابط/مسار واجهة الدفع الخاصة بزميلتك.
- الزر يرسل تلقائيًا في الرابط: amount + مدة التمديد، ويضع بيانات التمديد كاملة في sessionStorage باسم lockaExtensionPayment.
- بعد نجاح الدفع، واجهة الدفع تحتاج حفظ نفس بيانات lockaExtensionPayment باسم lockaPaidExtension ثم العودة إلى manage-booking.html، وبعدها تحدث واجهتي تاريخ ووقت الانتهاء تلقائيًا.

3) ربط بيانات الحجز:
- لا توجد بيانات ثابتة للمبنى أو الدور أو اللوكر أو أوقات الحجز.
- يمكن تمريرها من الواجهات الأخرى في sessionStorage باسم lockaBooking أو عبر Query Parameters.
- الحقول المدعومة: locker, building, floor, date, start, end, originalMinutes.
- مثال sessionStorage:
  {
    "locker":"12",
    "building":"كلية الحاسب",
    "floor":"الدور الأول",
    "date":"2025-08-25",
    "start":"09:00 ص",
    "end":"10:00 ص",
    "originalMinutes":60
  }

4) الإلغاء:
- عند تأكيد الإلغاء تختفي تفاصيل الحجز ويتم حذف بيانات الحجز والتمديد من sessionStorage.

5) الشعار:
- يستخدم شعار LOCKA الموجود داخل assets/locka-logo.jpg.
